Tender Intelligence — Nightly Process Flow

Runs automatically at 06:00 via cron on Azure VM

1

Query Hilma API

Fetch new notices published since last run

Filter by CGI-relevant CPV codes: 72 (IT), 48 (software), 79 (consulting), etc.

Also search by Finnish IT keywords: tietojärjestelmä, ohjelmisto, digitalisaatio

Result: ~200 structured tenders with CPV codes, estimated values, organisation IDs

⏱ ~2 seconds

Tech: requests → api.hankintailmoitukset.fi (REST API)

2

Launch Chrome + Login to tarjouspalvelu.fi

Open Chrome via Xvfb virtual display

Navigate to tarjouspalvelu.fi → Cloudflare auto-resolves

Enter email → SSO redirect to Cloudia → Enter password → Login button (ActionChains)

Switch UI to Finnish

Retry up to 3 times on failure

⏱ ~40 seconds

Tech: undetected-chromedriver + Selenium + ActionChains

3

Apply Search Filters + Scrape Listings

Set ilmoitustyyppi filter: Kilpailu, Suunnittelu, DPS, Kansallinen, Tietopyyntö

Search returns ~1,700 tenders across all Finland

Scrape 5 pages × 20 tenders = 100 tenders (name, org, type, dates, description)

Result: 100 tenders from tarjouspalvelu.fi listing pages

⏱ ~50 seconds

Tech: JavaScript extraction from DOM, pagination via HaeSivu()

4

Detail Page Scraping (selective)

For selected tenders: click row → detail page opens (session preserved)

Click through 6 sidebar tabs: Summary, Publication Docs, Q&A, Terms, Procurement Object, Contacts

Collect text from each tab

Download all attachments as ZIP (/Zip/TarjousPyynnonLiitteet/{id})

Result: rich content + ZIP files for detail-scraped tenders

⏱ ~10 seconds per tender

Tech: ActionChains click (preserves session), sidebar button IDs sidebar0-8

5

Merge + Deduplicate

Compare 200 Hilma tenders with 100 tarjouspalvelu tenders

Match by title + organisation similarity (threshold 75%)

Merge: Hilma's CPV codes + estimated values + tarjouspalvelu's full content + attachments

Result: ~260 unique tenders. ~40 matched in both, ~160 Hilma-only, ~60 tarjouspalvelu-only

⏱ instant

Tech: SequenceMatcher fuzzy matching

Browser closed — remaining steps are API calls and local processing
6

Classify + Store

Rule-based classification: Kilpailu → open_competition, Suunnittelu → early_signal, Tulokset → closed

Handles both Finnish and English type labels

Store in SQLite with deduplication (tp_id as key)

Result: all tenders in database with category + status

⏱ instant

7

AI Summarization

Send each tender to OpenAI gpt-4o-mini

Prompt includes "CGI DOES / DOES NOT" list — AI knows CGI's domain

Returns: What, Who, Relevance, Key dates, Action

Marks irrelevant tenders as "NOT RELEVANT — Skip"

Uses detail tab text if available (richer), falls back to listing description

Result: English AI summary attached to each tender

⏱ ~2 minutes for 50 tenders

Tech: OpenAI API, ~$0.002/tender

8

Three-Tier Routing

Tier 1A: CGI own product name found (Aromi, Raindance, Titania...) → CRITICAL

Tier 1B: Partner platform found (SAP, Atlassian, AWS, Oracle...) → HIGH

Tier 2: Department keywords from routing_config.xlsx → email digest

Tier 3: No match → catch-all / General

129 product/platform names checked automatically. Keywords use Finnish stem matching.

Result: each tender assigned to 1+ departments

⏱ instant

9

Send Email Notifications

One HTML email per department

Tenders sorted: AI-relevant first → NOT RELEVANT last → unsummarized bottom

Badges: Competition / Info Request / Detail Page

CPV codes and estimated values shown (from Hilma)

Multiple recipients per department supported

Result: 3-10 emails sent to department contacts

⏱ ~15 seconds

Tech: SMTP (Gmail for demo, CGI mail for production)

10

Award Analysis (on results tenders)

For closed/awarded tenders: AI extracts winner name, winning price, bidder count, sector

Updates competitor profiles: win count, average contract value, sectors

Updates price intelligence: contract values by sector

Result: growing competitor + price databases

⏱ ~1 minute for 20 awards

Tech: OpenAI API structured extraction

Total nightly run: ~5-7 minutes. Cost: ~€0.20-0.50 per run (AI only). All data persisted in SQLite + downloaded ZIPs.

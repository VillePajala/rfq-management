Verdict

The VM is the floor. You need it for Chrome. Once you have a VM, everything else can run on it for free (SQLite, cron, .env, local files).

Azure-native services add €25-35/month for marginal benefits at this scale. Azure SQL, Blob Storage, Key Vault, Monitor — none of these solve a problem you actually have with 300 tenders/day on a single VM.

The only Azure service worth adding: Azure OpenAI (compliance + EU data residency) and Azure Monitor (know when it breaks). That's ~€5-10 extra on top of the VM.

Total recommendation: €60-70/month. VM + Azure OpenAI + basic monitoring. Add other services only when a specific need arises (multi-user database, external file sharing, security audit requirements).

Tender Intelligence — Future: AI Agents Architecture

How AI agents could perform deep analysis on tender data — reading PDFs, predicting prices, recommending bids.

The Problem Agents Solve

Today: AI summaries use listing descriptions and tab text (~1-2 pages of text per tender).

Tomorrow: AI agents read the actual tender documents (50+ page PDFs, Excel pricing sheets) and extract structured intelligence.

Key insight: 300+ organisations use different document formats. Template-based extraction is impossible. Multimodal AI reads any layout like a human — regardless of format.

🔍 Agent 1: Document Classifier

TRIGGER: New ZIP downloaded for a relevant tender

Unpacks the ZIP, lists all files, classifies each by type.

INPUT: ZIP file contents (file names, sizes, first page of each PDF)
OUTPUT: Classified file list — e.g. "tarjouspyyntö.pdf = RFP spec", "hintalomake.xlsx = pricing template", "liite3_arviointikriteerit.pdf = evaluation criteria"

Model: gpt-4o-mini (cheap, text-only classification from file names + first pages)

Cost: ~$0.001 per tender. Routes files to the right specialist agents.

📋 Agent 2: Requirements Extractor

TRIGGER: RFP spec document identified by Agent 1

Reads the main tender specification (PDF, often 20-80 pages). Extracts structured requirements.

INPUT: PDF pages as images (multimodal) or extracted text
OUTPUT: JSON — scope of work, technical requirements, qualification criteria (revenue thresholds, reference cases, certifications), contract duration, SLA requirements

Model: Claude Sonnet or GPT-4o (multimodal, reads tables and formatted PDFs)

Cost: ~$0.10-0.30 per document. Handles any layout — no templates needed.

⚖️ Agent 3: Evaluation Criteria Extractor

TRIGGER: Evaluation criteria document identified by Agent 1

Extracts the exact scoring model: what criteria, what weights, what scoring method.

INPUT: Evaluation criteria PDF/section (often a table with percentages)
OUTPUT: JSON — criteria names, weights (e.g. "Price 40%, Quality 35%, Experience 25%"), scoring method (points, pass/fail, ranking)

Model: Claude Sonnet or GPT-4o (multimodal, reads tables accurately)

Cost: ~$0.05-0.10 per document. Critical for bid/no-bid decision.

💰 Agent 4: Pricing Model Analyzer

TRIGGER: Pricing template (Excel) identified by Agent 1

Reads the pricing spreadsheet structure. Determines what kind of pricing is expected.

INPUT: Excel file — sheet names, column headers, cell structure
OUTPUT: JSON — pricing model type (hourly rates / fixed fee / per-user / per-transaction), price components, volume assumptions, option years

Model: gpt-4o-mini (structured Excel → text is straightforward)

Cost: ~$0.01 per file. Enables price prediction against historical data.

🎯 Agent 5: Bid Recommendation Engine

TRIGGER: All other agents have completed for a tender

Takes all extracted data + historical competitor/price intelligence and produces a recommendation.

INPUT: Requirements (Agent 2) + Evaluation criteria (Agent 3) + Pricing model (Agent 4) + Historical data (competitor wins, price benchmarks from database) + CGI capability profile
OUTPUT:
• Bid/No-Bid recommendation with confidence score
• Qualification assessment: does CGI meet the requirements?
• Price guidance: based on historical wins in this sector/size
• Competitor prediction: who's likely to bid, based on sector + keywords
• Risk flags: unusually tight deadline, unfamiliar technology, etc.

Model: Claude Opus or GPT-4o (complex reasoning, needs full context)

Cost: ~$0.30-0.50 per tender. Only runs on tenders CGI is considering — not all 300.

Implementation Roadmap

Phase 1 (now): Basic summaries + routing + email notifications — DONE

Phase 2 (weeks): Detail page scraping + ZIP downloads + SharePoint upload — MOSTLY DONE

Phase 3 (1-2 months): Agent 1 (file classifier) + Agent 2 (requirements extractor) — read PDFs, extract structured data

Phase 4 (2-3 months): Agent 3 (evaluation criteria) + Agent 4 (pricing) — enable price benchmarking

Phase 5 (3-6 months): Agent 5 (bid recommendation) — full decision support with historical data

Each phase delivers standalone value. No phase depends on completing all previous phases.
